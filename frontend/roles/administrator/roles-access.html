    How access will work

    • Permissions will be enforced by the backend, not by this page.
    • Admin Employee is a permission-based subrole within the Administrator module. An Administrator decides which administrative permissions it receives.
    • Approving organization information always requires the Approving information permission. AI agents never hold it.
    • Every permission change will be recorded in the audit log.
    • The development role switcher changes the interface only. It does not grant any of these permissions.
